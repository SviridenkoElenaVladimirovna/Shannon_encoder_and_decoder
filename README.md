## Description
Shannon_encoder_and_decoder - The project developed a Shannon encoder and decoder using a data structure to store the dictionary in memory and a file format to store the dictionary. Implemented mechanisms for encoding and decoding strings using this dictionary. Tests were written to verify that the decoder recovers the original data after encoding.
